    Flash Game Android v1.0.0

    离线 Flash 播放器。APK 里不含任何游戏，内容由你自己导入。

    怎么用

    • 「＋ 添加 SWF 文件」：导入 .swf，或 .exe（会尝试提取内嵌的 SWF）
    • 「＋ 添加游戏文件夹」：导入带 data/ 的多文件游戏
    • 点名字开始玩；长按可以重命名或删除

    播放时的按钮

    ⌨虚拟按键：左侧方向键，右侧动作键（Z X A S D C + 空格 / 回车）。长按 ⌨ 可调大小、透明度，并切换「手柄 / 全键盘」
    ⌨⌨全键盘模式：26 键 + 数字 + 空格/回车/退格，用于输密码、输入文字、敲秘籍
    秘籍多数这类游戏用方向键 + B 键组合作弊，例如「上上下下左右左右 ba」（无限火焰）。用全键盘模式可以直接点 B
    ⟳切换屏幕方向：竖屏 → 横屏 → 反向横屏
    ✥拖动模式：可拖画面、双指缩放（开启时游戏不接收点击）
    ＋ －放大 / 缩小
    ⤢复位
    ◱隐藏界面，点右上角 ☰ 恢复
    ← 返回回到列表

    打开网址

    可以直接加载网络上的 .swf。目标站点需允许跨域读取（CORS），否则会加载失败。

    改键

    虚拟按键发出的键位可以改，设置保存在本机。
